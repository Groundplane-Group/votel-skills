# votel-skills

Flattened mirror of the Generix-Marketing/agent-skills collection (MIT License, copyright GenerixMarketing), restructured so every skill sits at skills/<name>/SKILL.md. Made for import into Votel, whose importer only finds skills one level deep.

Source: https://github.com/Generix-Marketing/agent-skills
The only change from the source is the folder layout: category folders were removed and each skill moved up one level. No skill content was edited.
